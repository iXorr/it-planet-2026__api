## DESCRIPTION

Backend service for the Trampoline application, designed to help students and applicants discover job opportunities and career events in a unified platform.

The system provides listings and map-based visualization of opportunities, with role-based access for admins, employees, and applicants to manage and interact with the data.

The entire application was developed as part of the **"IF... ELSE" 2026 hackathon** from **IT-PLANET** company.

## USAGE

API documentation is available via Swagger UI on the attached website. You can use it to explore and test all available endpoints.
